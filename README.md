# 건강 지킴이 · SCI Health Tracker

척수손상(SCI) 참여자가 **직접** 매일의 건강 상태와 운동을 기록하고, 주기적인 **기능평가 설문**으로 재활 경과를 비교·분석하는 웹앱입니다.

> 순수 HTML/CSS/JS로 만든 정적 웹앱이며, 모든 데이터는 서버 전송 없이 사용자의 브라우저(localStorage)에만 저장됩니다.

## 주요 기능

- **온보딩 & 기능평가 설문 (21문항 / 5영역)**
  - 신체 기능 상태(팔 뻗기·잡기·앉기·서기·호흡)
  - 일상생활 자립도 · 이동 능력 · 활동 수준 · 신체/삶의 질
  - 각 문항 5단계(0~4점, 높을수록 좋은 상태)
- **비교 분석**: 초기 평가 vs 재평가 — 항목별·영역별·총점 변화와 추이 그래프
- **매일 기록**: 컨디션, 통증·경직, 배뇨/배변, 욕창, 활력징후, 운동
- **기록 목록 / CSV 내보내기 / 대시보드 / 내 정보**
- 모바일·데스크톱 반응형

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 화면 구조 (상단 네비 + 각 화면 + 온보딩) |
| `styles.css` | 디자인 |
| `app.js` | 전체 화면 로직 |
| `storage.js` | 데이터 저장 계층 (향후 로그인/백엔드 확장 대비) |
| `survey-data.js` | 기능평가 설문 문항 정의 |

## 로컬에서 실행

정적 파일이라 별도 빌드가 필요 없습니다. 아무 정적 서버로 열면 됩니다.

```bash
# 예: 파이썬 내장 서버
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 배포 (Vercel)

이 저장소를 Vercel에 연결하면 됩니다. 빌드 과정이 없는 정적 사이트이므로 별도 설정 없이 그대로 배포됩니다.

## 개인정보 & 보안 안내

- 입력한 모든 정보는 **이 기기의 브라우저에만** 저장되며 외부로 전송되지 않습니다.
- 다중 사용자 로그인/서버 저장은 포함되어 있지 않습니다. 실제 서비스로 운영하려면 백엔드 인증·저장소 연동이 필요합니다.
- 본 앱은 건강 상태 **기록·추적 보조 도구**이며, 의학적 진단·치료를 대체하지 않습니다.
